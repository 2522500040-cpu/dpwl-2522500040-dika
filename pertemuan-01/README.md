Jawaban: PHP terstruktur memiliki tanggung jawab yang sama, sedangkan MVC memiliki tugas dan tanggung jawab yang berbeda beda.

3. fungsi Model, View, dan Controller;
Jawaban: Model mengolah data, View menampilkan data, Controller menghubungkan antara model dan view.

4. alur request–response MVC;
Jawaban: saya ingin meminta gambar, lalu controller akan meminta gambar itu kemodel, dan model mengambil gambar itu dari database dan dikirim lagi kecontroller, setelah itu controller mengirim hasilnya ke view dan view menampilkannya ke saya.

5. pemetaan satu atau beberapa bagian/fitur aplikasi DPW ke Model, Controller, dan View disertai alasan;
Jawaban: contoh absensi kampus
model menyimpan jam masuk, NIM, dan status hadir ke tabel absensi di database.
contoller Mengecek apakah mahasiswa ini absennya di jam yang benar. Kalau benar, dia panggil AbsensiModel untuk simpan data, lalu suruh View menampilkan status "Absen Berhasil".
